# フェーズ4(うつしえ)の計画

創の確認ずみ。質問への答えは、いちばん下の「12. 質問への答え」にまとめた。答えと本文が食い違うところは、答えのほうに従う。

## 目的

共通の枠に、うつしえの本物を差し込む。よつつじは仮パズルのまま。仕様は docs/plan.md の「うつしえ」の節に従い、試作(docs/prototypes/utsushie.html)の問題の作り方・映り方・ドラッグで置く操作を土台に移す。試作の配色・文言・難易度・ヒント・「ステージをスキップ」ボタンは使わない。ほかのパズルで決めたこと(色・触感・ヒントの一言・確認などの間は受け付けない・1画面に収める・作り直さない)はそろえる。

## 1. ファイル

```
public/js/puzzles/utsushie/
├─ logic.js       画面を持たない計算(難易度表・切り分け・色分け・映り方・置けるか・ヒントの探し方)
└─ utsushie.js    表示と操作(盤面の絵・手持ち・ドラッグ・点線・ヒントの光・クリアの光り方)
public/css/screens.css          うつしえの手持ち・ピースの見た目を足す
public/js/ui/play.js            共通の枠の小さな直し(下の2)
public/js/puzzles/registry.js   うつしえの game を仮パズルから本物に替える
public/sw.js                    オフライン用の一覧に2つのファイルを足す
tests/utsushie.test.mjs         問題作り・映り方・ヒントの確かめ
```

## 2. 共通の枠の小さな直し(public/js/ui/play.js と css)

うつしえは盤面が横長(横に2つ)になり、手持ちのピースの置き場も要るため、枠に2つ足す。ほかのパズルの見た目は変わらない。

- **盤面の縦横の比**：今は盤面を正方形として場所いっぱいに広げている。パズルが比(横÷縦)を決められるようにする(決めなければ今までどおり正方形)。
- **盤面の下の場所(`ctx.bottom`)**：盤面と3つのボタンのあいだに、手持ちのピースを並べる場所を足す(質問4)。
- 確認・ルールの画面・クリアの帯が出ているあいだに受け付けないようにする仕組み(`inert`)を、盤面だけでなく、盤面の上と下の場所にもかける。手持ちのピースもドラッグできなくなる。

## 3. 難易度表(docs/plan.md どおり)

| ステージ | 見え方 | 盤面 | ピースの大きさ |
| --- | --- | --- | --- |
| 1〜20 | 横に2つ | 5×5 | 2〜4マス |
| 21〜40 | 横に2つ | 6×6 | 3〜4マス |
| 41〜60 | 4分割(左上と上) | 5×5 | 3〜4マス |
| 61〜80 | 4分割(左上と上) | 6×6 | 3〜4マス |
| 81〜100 | 4分割(左上だけ) | 5×5 | 3〜4マス |
| 101〜 | 4分割(左上だけ) | 6×6 | 3〜5マス |

- 最初から置いてあるピースは1〜20だけ。ステージ1でピースの半分(四捨五入)、そこからステージごとに少しずつ減らし、ステージ20で0個(`半分 × (20 − ステージ) ÷ 19` を四捨五入)。21からは0個。
- 段階は共通の `tierOf()` で決める。

## 4. 問題の作り方・映り方(試作を移す)

- **切り分け**：試作の `genTiling` をそのまま使う。正方形の盤面を、決めた大きさのピースにランダムに切り分ける(空きマスの少ない所から広げていく作り方)。切った向きのまま、順番を混ぜて手持ちに出す。必ず解ける。乱数は枠の `ctx.rng`。
  - 試作は、うまく切れないときにピースの最小の大きさを下げていた。表から外れてしまうので、ステージ1〜300を自動の確かめで全部作り、下げずに作れることを確かめる。
- **色**：その回の配色の8色を使う。となり合うピースはちがう色にする(試作と同じく順に塗り分ける)。最初から置いてあるピースは、その色をうすくした色で塗りつぶす。
- **映り方**(試作と同じ):
  - 横に2つ：右が置く盤面(太い枠)。左に、境目をはさんで左右反転で映る。
  - 4分割(左上と上)：右下が置く盤面。左上に点対称、上(右上)に上下反転で映る。左下は斜線のグレーで隠す。
  - 4分割(左上だけ)：右下が置く盤面。左上に点対称で映る。上と左下は斜線のグレーで隠す。
  - 置く盤面には何も残らない。境目の鏡の線(点線)と、4分割の真ん中の点は試作どおり描く。
- 隠れた盤面の斜線のグレーは、のびしろの障害物と同じ色(`--wall`・`--stripe`)にそろえる。

## 5. 画面

- **上の情報**：盤面の中身と進み具合の文は質問2。ヒント残りは枠が出す。
- **盤面**：試作と同じく、1枚の絵(canvas)に描く。描き直すのは絵の中身だけで、盤面の部品は作り直さない。暗い画面に切り替えたときや画面の大きさが変わったときも描き直す。
- **手持ち**(盤面の下)：ピースを小さく並べる。ピースの部品は最初に一度だけ作り、置いたら隠す・戻したら出すだけにする。
- 遊ぶ画面は1画面に収める。6×6の4分割でも、盤面が小さくなって収まるようにする。
- **ルール説明の文**(docs/plan.md どおり)
  - 太い枠の盤面にピースを置くと、境目を鏡にして、ほかの盤面に映る。
  - 置いた盤面には何も残らない。斜線の盤面は隠れていて見えない。
  - ピースは回せない。ドラッグで置く。
  - 置いたピースは外せない。1手戻すか最初からで直す。
  - ほかの盤面をすき間なく埋めたらクリア。

## 6. 操作・音・触感(試作を移す)

- 手持ちのピースをドラッグすると、指の少し上に浮いてついてくる(盤面と同じマスの大きさで)。
- 置ける場所に来ると、太い枠の盤面にだけ点線でピースの形が出る。映る先には、置くまで何も出ない。
- 置けない場所で指を離すと、ピースは手持ちに戻る。盤面の近くなら小さくゆれる。
- 映った先でほかのピースと重なるか、盤面からはみ出す場所には置けない(映り方は1対1なので、置く盤面で重ならない・はみ出さないことと同じ)。
- タップしても何も起きない。置いたピースは外せない。
- 最初から置いてあるピースは、1手戻す・最初からでも外れない。
- **音**：置いたとき「コトッ」。ゆれて戻るときの音は質問3。
- **触感**：ドラッグで置くので震えない(共通の決まりどおり)。

## 7. ヒント

- **戻し方**：のびしろと同じく「残りのピースで、すき間なく埋めきれる所」まで、自分で置いたピースを新しいほうから戻す(最初から置いてあるピースは戻さない)。
  - 埋めきれるかは、残ったマスを残りのピースで敷き詰められるかを試して調べる(向きは変えず、ずらすだけ。6×6でもすぐ終わる)。調べる数には上限をつけ、上限に達したら、答えの位置と違う所に置いたピースを戻す形に切り替える。
  - 答えはひとつとは限らないので、答えと違う位置でも、残りで埋めきれるなら戻さない。
- **光らせるもの**(質問1。おすすめは案C)
  - 案A：置く場所だけ。太い枠の盤面に、次に置く場所を点線で点滅させる。どのピースかは自分で探す。
  - 案B：ピースだけ。手持ちの中の、次に置くピースを点滅させる。どこに置くかは自分で探す。
  - **案C(おすすめ)**：その両方。手持ちのピースと、太い枠の盤面の置く場所を、同じ色の点線で一緒に点滅させる。答えそのものは置かない。ほかのパズルの「次にする場所を1つ光らせる」に近く、母にもわかりやすい。
- 一言：「2手戻しました。光っている所に置いてみよう」(戻すものがなければ「光っている所に置いてみよう」)。
- 光りは、次にピースを置くか、1手戻す・最初からを押すと消える。ヒントで戻した手は「1手戻す」では戻らない(ほかと同じ)。

## 8. クリア

- 手持ちのピースを全部置いたら(=すき間なく埋まったら)クリア。
- 埋まった盤面全体がふわっと光る(映った盤面を、明るくしてから戻す。約0.7秒)。そのあと共通の枠が「クリア。」の帯を出す。

## 9. 作る順番

1. 共通の枠の小さな直し(盤面の比・盤面の下の場所・受け付けない範囲)。まじきり・のびしろの見た目が変わらないことを見る。
2. `logic.js`(難易度表・切り分け・色分け・最初から置くピース・映り方・置けるか・ヒント)と、その自動の確かめ。
3. `utsushie.js`：盤面の絵、手持ち、ドラッグ、点線、ヒントの光、クリアの光り方。
4. 登録表を本物に替え、sw.js の一覧に足す。
5. PCで確かめ、GitHub の main に送る。iPhoneで確かめる。

## 10. 動作確認

### 自動の確かめ(`node --test`)
- 難易度表：ステージ 1・20・21・41・61・81・101・500 で、見え方・盤面・ピースの大きさが表どおり。
- ステージ1〜300の問題がすべて：ピースの大きさが表の範囲、全部のマス数が盤面と同じ、となり合うピースの色がちがう、最初から置くピースの数が表どおり(1で半分・20と21〜で0)。
- 同じステージ番号なら同じ問題になる。
- 映り方：3つの見え方で、置く盤面のマスが正しい位置に映る。
- ヒント：でたらめに何個か置いたあと、戻したあとの状態が残りのピースで埋めきれ、光らせたピースをその場所に置けばまだ埋めきれる。時間がかかりすぎない。

### PC(Chrome)
1. `npx serve public` を動かし、表示されたアドレスを開く。開発者ツールでスマホの大きさにする。
2. うつしえを開く(初めてならルールが出る)。左に映る盤面、右に太い枠の盤面、下に手持ち。最初から置いてあるピースがうすい色で見える。
3. ピースをマウスで引っぱる → 指(マウス)の少し上に浮く。置ける所で太い枠の盤面に点線が出る。離すと左の盤面に反転して映り、「コトッ」。
4. 置けない所で離す → 手持ちに戻る。盤面の近くならゆれる。ピースをクリックしても何も起きない。
5. ヒント → 埋めきれない置き方が戻り、ピースと置く場所が光る。3回で「飛ばす」。
6. 全部置く → 盤面がふわっと光り、「クリア。」の帯。
7. 保存を書き換えて、ステージ41(左上と上)・81(左上だけ)・101(6×6)を開き、隠れた盤面の斜線と、1画面に収まるかを見る。小さい画面(375×667)でも見る。

### iPhone(1台)
1. ホーム画面のアプリを一度完全に閉じてから開く。
2. うつしえを開く。初めてならルールが出る。「閉じる」で消える。
3. 手持ちのピースを指でドラッグ → 指の少し上に浮いてついてくる。画面がずれたりスクロールしたりしない。
4. 置ける所で点線が出て、離すと反対側に映り、「コトッ」と鳴る。震えない。
5. 置けない所で離す → 戻る。盤面の近くならゆれる。
6. ヒント → ピースと置く場所が光る。
7. 全部置く → 盤面がふわっと光り、帯が出る。
8. 確認・ルールの画面が出ているあいだは、ピースをドラッグできない。
9. 暗い画面でも、ピースの色・うすい色のピース・斜線の盤面・太い枠が見分けられるか。

## 11. 質問

1. **ヒントで光らせるもの**：案A(置く場所だけ)・案B(ピースだけ)・案C(両方。おすすめ)のどれにするか(7を参照)。
2. **上の情報の文**：
   - おすすめ：盤面の中身は「5×5・横に2つ」(4分割なら「5×5・4分割(左上と上)」など)、進み具合は手持ちの残り「あと4個」。
3. **ゆれて戻るときの音**：置けない所で離して、盤面の近くでゆれるときに、間違いの音(低いコトコト)を鳴らすか。おすすめは鳴らす(盤面から遠い所で離したときは鳴らさない)。
4. **手持ちの置き場所**：盤面の下(3つのボタンの上)に並べる(おすすめ。試作と同じ。指でつまんで上の盤面へ運ぶ)か、盤面の上に並べるか。
