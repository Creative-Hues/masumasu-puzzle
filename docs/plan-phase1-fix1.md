# フェーズ1 直し1：触感の作り方を変える

承認後、この計画をそのまま **docs/plan-phase1-fix1.md** に保存してから作業する。

## なぜ直すか

- iPhone(iOS 26.6.2)では、今の方法(画面の外に置いたスイッチを、プログラムから押したことにする)では震えない。iOS 26.5から効かなくなった。
- 創が確かめたところ、押す場所に透明なスイッチ部品を重ね、指で本当にそのスイッチを押してもらう方法なら、iOS 26.6.2でも震える。
- これに合わせて、震える場面を「盤面のマスをタップした瞬間」だけにしぼる(iPhoneもAndroidも)。

## 決まっていること(創の指示)

- 震えるのは、盤面のマスをタップした瞬間だけ(のびしろで置く、まじきりでタップして線を引く、仮パズルでマスをタップする)。
- はらう・なぞる・ドラッグと、間違いのときは震えない(Androidも同じ)。
- iPhoneは、マスの上に透明なスイッチ部品を重ねる。Androidは `navigator.vibrate`(震わせる命令)のまま。
- 設定の「触感」のオン・オフは残す。オフなら震えない。
- 共通部分(`public/js/core/haptics.js` と遊ぶ画面の枠)で用意し、各パズルはマスごとに使う。

## 作り方

### 共通部分：`bindCellTap(マス, { onTap, buzz })`(haptics.js に作る)

各パズルは、震わせたいマスにこれを1回つけるだけにする。中でやること：

1. **タップの判定を、指の動きで自分で行う。** 指が触れた所(pointerdown)と離した所(pointerup)を比べ、ほとんど動いていなければ「タップ」として `onTap` を呼ぶ。動いた距離の上限は決めておき(10pxくらい)、パズルごとに変えられるようにする。
   - クリック(click)の知らせには頼らない。透明なスイッチがあると、クリックが2回届いたり、震わせないために止めたクリックが届かなかったりするため。
2. **iPhone：透明なスイッチを重ねる。** マスの中に `<input type="checkbox" switch>` をマスと同じ大きさで重ね、透明にする(創が確かめた方法と同じ透明さ)。指はこのスイッチを本当に押すので、iOSが震わせる。
   - 指の動きの知らせ(pointerdown・pointermove・pointerup)は、スイッチからマス、盤面へと上に伝わる。パズル側のはらう・なぞる・ドラッグの仕組みは、今までどおり盤面で受け取れる。
   - **震わせないとき**は、スイッチが切り替わる直前の知らせ(click)を止める(`preventDefault`)。スイッチは切り替わらず、震えない。止めるのは次のとき：
     - `buzz()` が「震わせない」と答えたとき(間違いの手、もう埋まったマスなど)
     - 指が上限より動いたとき(はらう・なぞる・ドラッグ)
     - 設定で触感がオフのとき
3. **Android：** タップと判定し、`buzz()` が「震わせる」と答えたときだけ `navigator.vibrate(12)`。透明なスイッチは置かない。
4. iPhoneかどうかは「スイッチ部品が使えて、`navigator.vibrate` がない」で見分ける。どちらでもない端末(PCなど)は、タップの判定だけ行う。

- `buzz()` は「このタップが正しく置ける・引ける手か」をパズルが答えるもの。間違いの手には「震わせない」と答える。
- 前の方法(画面の外のスイッチをプログラムから押す `haptic()`)は消す。

### 遊ぶ画面の枠(`public/js/ui/play.js`)

- パズルに渡す道具から `haptic()` を外し、代わりに `tapCell(マス, { onTap, buzz })` を渡す(中身は上の `bindCellTap`)。
- 約束事の説明(`public/js/puzzles/registry.js` の上のほうの説明)も合わせて直す。

### 仮パズル(`public/js/puzzles/trial/trial.js`)

- マスの `click` をやめ、`ctx.tapCell(マス, { onTap: () => tap(i), buzz: () => 印があって、まだ押していないマスか })` にする。
- 印のないマス(間違い)は震えない。音(低いコトコト)はそのまま鳴る。
- マスの中に重ねるので、マスに `position: relative` をつける(CSS)。

### 設定画面(`public/js/ui/settings.js`)

- 触感をオンにしたときに試しに震わせていたのをやめる(マスのタップ以外では震わせない決まりのため。iPhoneではもう効かない)。

### 計画書の直し

- `docs/plan.md` の「音と触感」の触感の2行を、指示のとおりに書き換える：
  - 触感：iPhoneでもAndroidでも、盤面のマスをタップした瞬間だけ震える(のびしろで置くとき、まじきりでタップして線を引くとき)。はらう・なぞる・ドラッグの操作と、間違いのときは震えない。
  - iPhoneは、盤面のマスの上に透明なスイッチ部品を重ね、指で本当にそのスイッチを押してもらうことで震わせる。iOS 26.5から、プログラムから押したことにする方法では震えなくなったため。将来また使えなくなる可能性がある。
  (よつつじの「線が右の円につながったとき」も消える)
- `docs/plan-phase1.md` の「触感」の節に、「直し1で変えた。docs/plan-phase1-fix1.md を見る」と一言足す。

## 確かめ方

### PC
1. `node --test`：今の12個に加え、「ほとんど動かなければタップ、動いたらタップでない」の判定の確かめを足す。
2. `npx serve public` で配り、自動で動かしたChromeで、仮パズルのマスを押す。1回押して1回だけ置かれる(2回にならない)こと、ヒント・クリアの帯・一覧がこれまでどおり動くことを見る。
3. 指を動かした場合(押してから20px動かして離す)に、置かれないことを見る。

### iPhone(1台)
1. ホーム画面のアプリを開き直す(新しい版に入れ替わるよう、一度閉じてから開く)。
2. 仮パズルで、印のマスをタップ →「コトッ」と鳴り、軽く震える。
3. 印のないマスをタップ →「×」と低い音。震えない。
4. 押したまま指をすべらせて離す → 置かれず、震えない。
5. 設定で触感をオフ → 印のマスをタップしても震えない。オンに戻すと震える。
6. ボタン(ヒント・1手戻す など)を押しても震えない。音はこれまでどおり鳴る。

## 気をつけること

- 「止めたクリックでは震えない」ことは、iPhoneの実機でしか確かめられない。もし間違いのマスでも震えてしまったら、止める場所を「指が触れた瞬間(touchstart)」に変える。ただしそうすると、そのマスから始めた指の動きで画面がスクロールしなくなるので、そのときは相談する。
