# フェーズ6 直し1：最初の画面・ヒント・遊ぶ画面のすき間

承認後、この計画をそのまま **docs/plan-phase6-fix1.md** に保存してから実装する。

## なぜ直すか

創が遊んでみて、気になった所が4つあった。

1. 最初の画面を、アプリアイコンのような2×2のマスに並べたい。
2. まじきりのヒントが多すぎる(線が2本しかないのに3回使える)。よつつじのヒントは1マスずつで少なすぎる。
3. 遊ぶ画面で、上の情報・盤面・下のボタンが離れすぎている。
4. 計画書(docs/plan.md)も、上の3つに合わせて直す。

## 1. 最初の画面を2×2のマスに並べる

- 4つのパズルを、2×2の正方形のマスに並べる。左上のびしろ・右上まじきり・左下よつつじ・右下うつしえ(登録表の順のまま)。
- 各マスは白いマス(盤面のマスと同じ `--cell`)で、灰色の地(`--bg`)の上に置く。地の色は塗り分けない。マスの角の丸みは、今のカードと同じ16px。マスとマスのすき間は12px。
- 各マスの中は、上に小さな絵(今と同じ絵)、下に名前とひとこと説明。
  - 小さな絵は、マスが大きくなるので、今の64pxから、マスの幅の約半分(小さいiPhoneで約80px)に大きくする(絵は拡大してもぼやけない図なので、中身は同じ)。
  - 名前とひとこと説明は、まん中ぞろえ。
- マス全体を押すと、そのパズルが開く(今と同じ)。
- 上の「ますます」と「設定」は今のまま。小さいiPhone(375×667)でもスクロールせずに4つが見えるようにする。
- 直すファイル：public/js/ui/home.js(並べ方)、public/css/screens.css(カードの見た目)、public/js/ui/thumbs.js(大きさは CSS で変えるので、中身はそのまま)。

## 2. ヒントの数と光り方

### 回数をパズルごとに決められるようにする(共通の枠)
- 今は共通の枠(public/js/ui/play.js)が、どのパズルも3回で数えている(`createHintCounter()`)。
- パズルが「このステージのヒントの回数」を決められるようにする(パズルの約束事に `hintLimit(stage)` を足す。なければ今までどおり3回)。上の「ヒント残り」と、使い切ったら「飛ばす」になる所は、この回数で動く。
- 約束事の説明(public/js/puzzles/registry.js の上の説明)にも書き足す。

### まじきり
- ヒントの回数 =「線の本数 − 1」(上限3回)。
  - 1〜20(縦1・横1で2本)：1回
  - 21〜40(3本)：2回
  - 41〜(4本以上)：3回
- 直すファイル：public/js/puzzles/majikiri/majikiri.js(`hintLimit`)。

### よつつじ
- 回数は3回のまま。
- 1回のヒントで、選んだ線が次に進む所から「次の曲がり角まで(まっすぐ進む分)」をまとめて点滅させる。
  - 例：答えの線が、次に右・右・右と進んでから下へ曲がるなら、右へ進む3マスを光らせる(3マス目が曲がり角)。
  - 線がまだないとき(左の円から始めるとき)は、左の円から右へまっすぐ進む分を光らせ、左の円も一緒に光らせる(今と同じ)。
  - 交差マスは、まっすぐ通り抜けるので、そのまま数えて先まで光らせる。
  - 右の円のとなりのマスに着いたら、そこで止める。
- 光らせ方は今と同じ(共通の緑の点線で、マスを1つずつ囲む)。一言も今と同じ(「2本戻しました。光っている所までなぞってみよう」)。
- 直すファイル：public/js/puzzles/yotsutsuji/logic.js(`hintOf` が光らせるマスを並びで返す)、yotsutsuji.js(並びを全部囲む)。

### のびしろ・うつしえ
- 今のまま(3回・1つ光らせる)。

## 3. 遊ぶ画面のすき間

- 今は、盤面の場所が残りの高さいっぱいに広がり、盤面はその場所のまん中に置かれている。そのため、背の高い画面では、上の情報と盤面、盤面と下のボタンのあいだが大きくあく。
- 直し方：
  - 上のバー(もどる・ステージ番号・一覧)・上の情報・盤面の上(まじきりの組み合わせ・のびしろの丸)・一言・盤面・盤面の下(うつしえの手持ち)・3つのボタン・「ルール」を、ひとまとまりにして、画面の上下のまん中に置く。余った場所は、画面の上と下に同じくらいずつ分ける。
  - 盤面の大きさは、今と同じく「入るだけ大きく」する。ただし、残りの高さは、ほかの部品の高さを測って計算する(共通の枠で、画面の大きさや部品の高さが変わるたびに測り直す)。盤面の場所は、盤面の大きさぴったりにする。
  - 盤面の幅が先にいっぱいになる(横に余る)画面では、上下に余った場所ができ、それを上と下に分ける。
- 4つとも、1画面に収まる・スクロールしないのは今のまま。
- 直すファイル：public/js/ui/play.js(残りの高さを測る)、public/css/screens.css(まとまりを上下のまん中に置く)。

## 6. 追加の直し(画面写真を見て)

- **遊ぶ画面**：「もどる・◀ステージ▶・一覧」は、どのパズルでもいちばん上に固定した(前は、まとまりと一緒にまん中へ寄り、パズルごとに位置が変わっていた)。その下の、盤面の中身・進み具合・ヒント残りと、盤面と、下のボタン(と、うつしえの手持ち・ルール)を、ひとまとまりにして、残りの場所のまん中に置く。
