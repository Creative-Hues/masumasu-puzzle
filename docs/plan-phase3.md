# フェーズ3(のびしろ)の計画

創の確認ずみ。質問への答えは、いちばん下の「12. 質問への答え」にまとめた。答えと本文が食い違うところは、答えのほうに従う。

## 目的

共通の枠に、のびしろの本物を差し込む。よつつじ・うつしえは仮パズルのまま。仕様は docs/plan.md の「のびしろ」の節に従い、伸びる動きと問題の作り方は試作(docs/prototypes/nobishiro.html)を土台にする。試作の配色(淡色とくすみの10種類)と難易度の段階は古いので使わない。まじきりで決めたこと(色の使い方・間違いの音・ヒントの一言・確認などの間は盤面が受け付けない)は、のびしろでもそろえる。

## 1. ファイル

```
public/js/puzzles/nobishiro/
├─ logic.js       画面を持たない計算(難易度表・伸び方・問題作り・ヒントの探し方)
└─ nobishiro.js   盤面の表示と操作(置く・番号・にじむ動き・上の丸・一言・ヒントの光・クリアの光り方)
public/css/screens.css          のびしろの盤面・障害物・番号・上の丸・にじむ動きの見た目を足す
public/js/puzzles/registry.js   のびしろの game を仮パズルから本物に替える
public/sw.js                    オフライン用の一覧に2つのファイルを足す
tests/nobishiro.test.mjs        問題作り・伸び方・ヒントの確かめ
```

## 2. 難易度表(docs/plan.md どおり)

| ステージ | 盤面 | 置ける数 | 障害物 |
| --- | --- | --- | --- |
| 1〜20 | 5×5 | 3〜4個 | 4個 |
| 21〜40 | 6×6 | 4〜5個 | 6個 |
| 41〜60 | 6×6 | 5〜6個 | 6個 |
| 61〜80 | 7×7 | 5〜7個 | 8個 |
| 81〜100 | 7×7 | 6〜8個 | 8個 |
| 101〜 | 8×8 | 7〜10個 | 10個 |

段階は共通の `tierOf()` で決める。

## 3. ルールと伸び方

- 空いたマスに置くと、上下左右に、壁(外側・障害物)か色のマスにぶつかるまで伸びる(試作の `spread` と同じ)。
- 先に伸びた色は、あとから置いたものの壁になる。
- 空いたマスが全部埋まったらクリア。まれに「置ける数」より少なく埋まることがあり(計画書のとおり)、そのときもクリア。
- 「置ける数」を全部使っても埋まらなければ、一言「埋まりきらなかった。1手戻してみよう」と間違いの音(低いコトコト)。

## 4. 問題の作り方(試作と同じ考え方)

1. 障害物を、段階の数だけランダムなマスに置く(乱数は枠から渡される `ctx.rng`。同じステージ番号ならいつも同じ)。
2. 空いたマスにランダムに置いていく遊び方を400回試し、全部埋まったうちいちばん少ない数を「置ける数」にする。そのときの置き方を「答えの置き方」として持っておく(ヒントに使う)。
3. 「置ける数」が段階の範囲(例：1〜20なら3〜4個)に入れば採用。入らなければ、障害物を置き直してやり直す。
- ステージ1〜300を自動の確かめで全部作ってみて、作れないステージがないか、1問を作る時間を確かめる(目安：PCで0.1秒以内)。遅い段階があれば、試す回数を減らすなどして合わせる。

## 5. 画面

### 上の情報(共通の枠)
- 盤面の中身と進み具合の文は質問1。ヒント残りは枠が出す。

### 盤面の上(`ctx.top`)
- 置ける数だけ丸を並べる。置くと、その順番の色に変わる(試作と同じ)。

### 盤面
- 空いたマスは白(暗い画面では濃い灰色)、障害物は斜め線のマス(共通の色 `--wall`・`--stripe`)。
- 置いたマスには、置いた順番の数字を白い丸の中に出す。
- 色は、その回の配色の8色を置いた順に使う(1個目は1色目…)。9個目からは質問2。
- **盤面のマスは最初に一度だけ作り、そのあとは中身だけ書き換える。** 試作のように置くたびに盤面を作り直すと、触感用の透明なスイッチが指を離す前に消えてしまい、iPhoneで震えなくなるため。色・番号の部品は指の邪魔をしないように(`pointer-events: none`)する。

### にじむように伸びる動き(試作と同じ作り)
- 置いたマスはすぐに色がつき、そこから絵の具が紙ににじむように、色の先頭をぼかしながら上下左右へ流れる。端まで約0.12秒(ほぼ一瞬)。流れ終わるとマスごとにくっきり塗られる。
- じわっと始まり、途中は速く、端でやさしく止まる流れ方(試作の計算をそのまま使う)。
- 動きを減らす設定の端末では、流れずにすぐ塗られる。

### ルール説明の文(docs/plan.md どおり)
- 丸の数だけ、空いたマスに置いて、全部埋めたらクリア。
- 置くと、上下左右に、壁か色のマスにぶつかるまで伸びる。
- 先に伸びた色は、あとから置いたものの壁になる。

## 6. 操作・音・触感

- 空いたマスをタップして置く。埋まったマス・障害物、置ける数を使い切ったあとのタップは何もしない。
- 音：置いたとき「コトッ」。
- 触感：空いたマスをタップして置いたときだけ(共通の `ctx.tapCell`。`buzz` は「空いたマスで、まだ置ける」とき)。
- 1手戻す・最初からは、置いた順に戻す・全部戻す。
- 確認・ルールの画面・クリアの帯が出ているあいだは、盤面が受け付けない(共通の枠のまま)。

## 7. ヒント

- 「残りの数で全部埋めきれる所」まで、置いた手を新しいほうから戻す。そのあと、次に置く場所を1つ光らせる(試作と同じ)。
- 一言：「2手戻しました。光っている所に置いてみよう」(戻すものがなければ「光っている所に置いてみよう」)。
- 光っているマスは、次に置くか、1手戻す・最初からを押すと消える。
- **探し方**：
  - 置いた手が「答えの置き方」と最初から同じ順番なら、答えの次の1手をそのまま光らせる(すぐ終わる)。
  - そうでなければ、試作と同じく「残りの数で埋めきれるか」を全部試して探す(同じ盤面の状態は覚えておき、2回調べない)。
  - 8×8で探すのに時間がかかりすぎる場合に備え、調べる数に上限をつける。上限に達したら、答えの置き方と同じ所まで戻して、答えの次の1手を光らせる。
- ヒントで戻した手は「1手戻す」では戻らない(まじきりと同じ)。

## 8. クリア

- 1個目、2個目…と、置いた順に、その色のマスが光る(試作と同じ。1色ごとに約0.28秒ずつずらす)。光り終わったら、共通の枠が「クリア。」の帯を出す。

## 9. 作る順番

1. `logic.js`(難易度表・伸び方・問題作り・ヒントの探し方)と、その自動の確かめ。
2. `nobishiro.js`：盤面、置く、番号、上の丸、にじむ動き、一言、ヒント、クリアの光り方。
3. 登録表を本物に替え、sw.js の一覧に足す。
4. PCで確かめ、GitHub の main に送る。iPhoneで確かめる。

## 10. 動作確認

### 自動の確かめ(`node --test`)
- 難易度表：ステージ 1・20・21・41・61・81・101・500 で、盤面・置ける数の範囲・障害物の数が表どおり。
- 伸び方：小さな盤面で、壁・障害物・先に伸びた色で止まる。
- ステージ1〜300の問題が全部作れて：障害物の数が表どおり、「置ける数」が範囲に入る、答えの置き方で本当に全部埋まる。1問の時間も測る。
- 同じステージ番号なら同じ問題になる。
- ヒント：埋めきれない手を戻し、光らせた場所に置くと、残りの数で埋めきれる。8×8でも時間がかかりすぎない。

### PC(Chrome)
1. `npx serve public` を動かし、表示されたアドレスを開く。開発者ツールでスマホの大きさにする。
2. のびしろを開く(初めてならルールが出る)。上に丸が置ける数だけ並ぶ。
3. 空いたマスをクリック → 色がにじむように伸び、白い丸の中に「1」。上の丸が1つその色に変わる。
4. 置ける数を使い切って埋まらない →「埋まりきらなかった。1手戻してみよう」。
5. ヒント → 埋めきれる所まで戻り、マスが1つ光る。3回で「飛ばす」。
6. 正しく置いて全部埋める → 置いた順に色が光り、「クリア。」の帯。
7. ステージ21・41・61・81・101(自動の確かめで見る)と、8×8の画面が1画面に収まるか(保存を書き換えて開く)。

### iPhone(1台)
1. ホーム画面のアプリを一度完全に閉じてから開く。
2. のびしろを開く。初めてならルールが出る。「閉じる」で消える。
3. 空いたマスをタップ → 絵の具がにじむように伸び、「コトッ」と鳴って軽く震える。番号が出る。
4. 色のついたマス・斜め線のマスをタップ → 何も起きない。震えない。
5. 使い切って埋まらない → 一言と低い音。震えない。
6. ヒント → 戻って、光ったマスに置けば埋めきれる。
7. 全部埋める → 置いた順に光り、帯が出る。
8. 暗い画面でも、斜め線のマス・色・番号が見分けられるか。

## 11. 質問

1. **上の情報の文**：盤面の中身と進み具合を何と出すか。
   - おすすめ：盤面の中身は「5×5・4個置く」、進み具合は「あと2個」。
   - 上に丸が並ぶので、進み具合は出さず、盤面の中身「5×5」だけにする案もある。
2. **9個目からの色**：101〜は最大10個置くので、配色の8色では足りない。9個目・10個目を1色目・2色目に戻すか(おすすめ。番号で見分けられる。となり合うことはまれ)、ほかの決め方にするか。
3. **少ない数で埋まったとき**：まれに「置ける数」より少なく埋まる問題がある。そのときもふつうにクリアにする(計画書と試作のとおり)。それとも、何か一言を出すか(試作は帯に「4個で埋まりました」と出していた)。おすすめは、ふつうのクリアのまま何も出さない。

## 12. 質問への答え(創の回答)

| # | 質問 | 答え | 作りへの反映 |
| --- | --- | --- | --- |
| 1 | 上の情報の文 | おすすめのとおり | 盤面の中身は「5×5・4個置く」(4は置ける数)、進み具合は「あと2個」 |
| 2 | 9個目からの色 | 1色目・2色目に戻す | 色は8色を置いた順にくり返して使う(9個目は1色目、10個目は2色目) |
| 3 | 少ない数で埋まったとき | ふつうのクリア | 何も出さない |

- 「4個置く」の数は問題を作らないとわからないので、盤面の中身の文を出すときにも同じステージの問題を作る(作った問題は覚えておき、盤面を出すときにそのまま使う。同じステージ番号なら同じ問題になるので食い違わない)。
