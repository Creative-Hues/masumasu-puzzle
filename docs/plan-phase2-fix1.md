# フェーズ2 直し1：スクロールと拡大をなくす

## なぜ直すか

- 遊ぶ画面が縦に長く、スクロールが要る。盤面の上で指を動かすと、画面がずれたり引っぱられたりすることがある。
- 2本指で広げたり2回タップしたりすると、画面が拡大してしまう。

## 決まっていること(創の指示)

- **拡大**：どの画面でも、2本指で広げる拡大と、2回タップの拡大をしない。
- **スクロール**：
  - 遊ぶ画面は1画面に収め、スクロールしない。iPhoneの小さい画面でも収まるようにする。
  - 一覧・設定・最初の画面は、入りきらないときだけスクロールしてよい(今のまま)。
  - 盤面の上で指を動かしても、画面がずれたり引っぱられたりしないようにする。
- **ルールの説明**：
  - 遊ぶ画面の下にいつも出すのをやめる。
  - 3つのボタン(1手戻す・最初から・ヒント)の下に、小さく「ルール」のボタンを置く。
  - 押すと、ルールの説明が画面の真ん中に出る。「閉じる」で戻る。
  - パズルごとに、初めて開いたときだけ自動で出す。出したことは端末に保存する。

## 作り方

### 拡大をなくす(全部の画面)
- 画面の大きさの指定(viewport)に「拡大しない」(`maximum-scale=1, user-scalable=no`)を足す。
- iPhoneのSafariはこの指定を無視することがあるので、次も合わせて行う：
  - 画面全体に `touch-action: pan-x pan-y`(指でのスクロールだけ許し、2本指の拡大と2回タップの拡大を止める指定)。
  - iPhoneの2本指の動きの知らせ(gesturestart など)を止める。

### 遊ぶ画面を1画面に収める
- 遊ぶ画面を開いている間だけ、ページ全体を画面の高さに固定し、スクロールしないようにする(`html` に印のクラスをつけて切り替える)。一覧・設定・最初の画面は今のまま。
- 遊ぶ画面の中は、上から「上のバー・情報・盤面の上(組み合わせなど)・一言・盤面・3つのボタン・ルールのボタン」と並べ、**盤面が残りの場所いっぱいの正方形**になるようにする(幅と高さの小さいほうに合わせる)。小さいiPhoneでは盤面が少し小さくなる。
- 遊ぶ画面全体に `touch-action: none`(指の動きで画面を動かさない指定)。盤面は前から同じ指定。ボタンのタップはこれまでどおり効く。
- 引っぱったときに画面がびよんと動く(はね返り)のも止める(`overscroll-behavior: none`)。
- iPhoneの画面下の丸みの所(ホームバー)にボタンがかからないよう、下に余白をとる。

### ルールのボタンと説明
- 共通の枠(`public/js/ui/play.js`)に作る。各パズルは今までどおり `rules`(文の配列)を渡すだけ。
- 「ルール」のボタン：3つのボタンの下に、小さな文字のボタン。
- 説明：画面の真ん中に白い札で出し、うしろは少し暗くする。札の中は「ルール」の見出し、ルールの文、「閉じる」のボタン。文が長いときは札の中だけスクロールできる。
- 初めてかどうかは、保存(`public/js/core/storage.js`)に「ルールを出したパズル」の一覧として持つ。遊ぶ画面を開いたとき、まだ出していなければ自動で出し、出したと記録する。古い保存データにこの項目がなくても動くようにする。

### 計画書の直し
- `docs/plan.md` の「画面」：
  - 下に「1手戻す」「最初から」「ヒント」のボタン。その下に小さく「ルール」のボタン。押すとルールの説明が画面の真ん中に出て、「閉じる」で戻る。パズルごとに、初めて開いたときだけ自動で出す。
  - 見た目はすっきり無地。明るい画面と暗い画面の両方を用意する。遊ぶ画面は1画面に収め、スクロールしない。どの画面も拡大(2本指で広げる・2回タップ)はしない。
- `CLAUDE.md` の「画面」の行も、計画書と食い違わないように合わせる(「その下にルールの説明」→「その下に小さく『ルール』のボタン」)。

## 確かめ方

### 自動の確かめ(`node --test`)
- 保存：ルールを出したパズルを覚え、読み直しても残る。古い保存データ(この項目がない)でも動く。

### PC(Chrome)
- iPhoneの小さい画面(375×667)と、ふつうの画面(390×844)の大きさで、仮パズルと、まじきりのステージ1・101(組み合わせの札が3行になる)を開き、スクロールが要らない(ページの高さが画面の高さに収まる)ことを見る。
- 初めて開くとルールが出て、「閉じる」で消え、開き直しても出ないことを見る。「ルール」のボタンで何度でも出ることを見る。
- 一覧・設定・最初の画面は、これまでどおりスクロールできることを見る。

### iPhone(1台)
1. ホーム画面のアプリを一度完全に閉じてから開く。
2. まじきりを開く → 初めてならルールが真ん中に出る。「閉じる」で消える。もう一度開いても出ない。「ルール」のボタンで出る。
3. 遊ぶ画面が1画面に収まり、上下に動かせない。盤面の上で指を動かしても画面がずれない。
4. どの画面でも、2本指で広げても、2回タップしても拡大しない。
5. ステージ101のように組み合わせが多いときも、ボタンまで画面に収まる(◀▶で進めないときは、PCでの確かめで見る)。
6. 一覧で、ステージが多いときはスクロールできる。
